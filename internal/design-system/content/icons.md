# Icons

The Lucide icons (`lucide-react`) that the components render themselves, exported at 24px with a 2px round stroke.

- Ink: zinc-900 — an `<img>` cannot inherit color. In code, import the icon from `lucide-react` so it takes
  `currentColor`.
- Components render them at 16px (`size-4`), 12–14px inside `xs`/`sm` buttons.

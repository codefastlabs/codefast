# Logos

The codefast mark and lockups, copied from `apps/web/public/brand`.

- `mark.svg` — light grounds. Lead tile `#0084d1` (sky-600), trailing tiles `#171717` at 40%, 40%, 15%.
- `mark-dark.svg` — dark grounds. Lead tile `#00bcff` (sky-400), trailing tiles `#fafafa` at 40%, 40%, 15%.
- `mark-mono.svg` — single ink, `#171717` (its `currentColor` is set on the root; recolor in code, not in `<img>`).
- `lockup-horizontal.png` / `lockup-horizontal-dark.png` (680×176) — mark + wordmark for headers.
- `lockup-stacked.png` / `lockup-stacked-dark.png` (480×336) — square placements.
- `readme-banner.png` (2560×640) — repository README header.

Never recolor, outline, rotate or re-space the tiles. Keep clear space of one tile around the mark.
